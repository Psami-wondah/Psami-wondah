## Featured Projects

### Koinovera

A community-powered evidence and research platform where users can create public claims, add references and collaboratively assess the quality of supporting or disputing evidence.

**Technologies:** React, TypeScript, NestJS, PostgreSQL and Auth0

Key areas include:

* Claims and evidence management
* Source classification
* Tags and categories
* Community ratings
* Comments and review notes
* Moderation and reporting
* Role-based access control

### Low-Vision Smart Glasses Assistance System

An MSc research project exploring how smartphones and USB-C smart glasses can support people with peripheral-vision loss or tunnel vision.

The system explores:

* Custom Android secondary-display output
* Camera-based scene processing
* Object and sign identification
* Visual information enhancement
* Audio-based assistance
* Multimodal accessibility

**Technologies:** Kotlin, Android, USB-C displays and computer vision

### Global Health Data and Reporting Tools

At Zimmerman B.V., I contribute to interactive data and reporting platforms used to explore complex financial, programme and public-health datasets.

My contributions include chart configuration, report-building workflows, responsive layouts, asset handling, CMS integrations, testing and backend performance improvements.
